## Implementation and usable configuration

- A macOS login automatically attempts hardware H.264 and audio: direct first, companion SSH after transport/media failure, then ordinary VNC. Credential/permission rejection is terminal. These are not editor options. One **Companion Remote Login** selector accepts any saved SSH; file access additionally requires SFTP on. New SSH defaults SFTP on, existing off retained; legacy relay selections migrate. SSH borrows the selected profile ID so terminal/files/media can share a transport. The old streaming copy remains retained, but ordinary macOS-login profiles now use the same automatic policy.
- `MacHevcSession`: RSA1 type33 or DH type30 authentication, optional SessionSelect, bounded encrypted control/media. A 500ms absent-prompt probe sends the viewer prelude; partial headers retain the normal read deadline and fail if truncated. Experimental mutual-proof SRP remains off. Authentication still reaches a Mac lock screen on this tested host. A confirmed toolbar action submits the saved password and Return once to the selected own-account empty password field, on streaming and standard VNC fallback; no blind retry or verified authentication-only bypass.
- `MacAvcStream`/packet order: validated avcC/geometry, bounded4MiB access units,100ms/4096-packet/8MiB reorder window, duplicate/late exclusion, validated source retirement and codec reset. New sources retarget FIR. Geometry re-offers occur only on actual changes. Hardware codec identity is checked.
- `MacScreenAudio`: separate audio SRTP keys/PT101, raw Apple AAC-ELD-SBR ASC `f8e65132e000`, MediaCodec, bounded queue, PCM16 AudioTrack, heartbeat/mute/owned-worker teardown. `VncBridge` exposes its AudioTrack session ID and binds it to the owning Horizon window space through existing `QuestSpatialAudio`; the 500 ms desktop poll follows space changes and forgets bindings on close. Older Horizon versions retain Android fallback.
- `VncSessionConnection` owns an optional in-memory Perl UDP-over-SSH exec-channel relay and a reference-counted lease to the selected SSH transport. This is **not an SSH dynamic proxy**. UDP 5901 carries video/RTCP; UDP 5900 carries audio/control, not separate displays. Per-datagram port labels are preserved. No Mac files/services installed; relay closes on EOF/session teardown and expires after 600s idle. One streaming session owns fixed local media ports.
