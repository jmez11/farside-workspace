Resolve each profile's own saved credential; validate SSH `id -un` internally and pass its short username explicitly to SessionSelect. Never derive it from the VNC long display name. Require fresh authenticated SSH and nonblank standard VNC before each media experiment. Abort on baseline failure; stop further VNC attempts after credential/SessionSelect rejection. After media failure, check retained SSH liveness and one fresh VNC baseline after the quiet interval. Retained SSH proves continuity, not fresh authentication. No wrong-password tests, deleted-profile retries or security-setting changes.
